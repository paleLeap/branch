# Bundled data

## cities.csv.gz

20,202 US and Canadian populated places of 1,000 people or more:
`name, admin1, country, lat, lon, population`, sorted by population.

Derived from **GeoNames** `cities1000`, licensed **CC BY 4.0**
(https://www.geonames.org/). Attribution is required when distributing Branch —
see the NOTICE file at the repo root.

Bundled rather than fetched so the location field works with no network, no API
key and no account, like the rest of the program.
